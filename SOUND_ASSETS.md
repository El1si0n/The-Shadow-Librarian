# Liste des Sons Requis - The Shadow Librarian

## 🎧 Ambiance (Musique / Fond)
Format recommandé : `.mp3` ou `.ogg` (boucle propre).

| Nom Fichier | Description | Utilisation |
| :--- | :--- | :--- |
| `ambiance_library.mp3` | Calme, poussière, légers craquements de bois, pages tournées au loin. | **Base** (Phase 1 & 2). |
| `ambiance_void.mp3` | Bourdonnement grave, vent souterrain, écho métallique. Inquiétant. | **Phase 3** (Architecte) ou Savoir > 10. |
| `ambiance_glitch.mp3` | Sons distordus, fréquences cassées, murmures incompréhensibles (stéréo). | **Savoir > 30** (Folie). |

## 🔊 Effets Sonores (SFX)
Format recommandé : `.wav` ou `.mp3` (courts, < 1 sec).

### Interface & Actions
| Nom Fichier | Description | Utilisation |
| :--- | :--- | :--- |
| `sfx_click_pen.mp3` | Bruit sec d'une plume qu'on trempe ou qui écrit un trait rapide. | Clic sur **"Tremper la plume"**. |
| `sfx_page_turn.mp3` | Bruit de papier froissé ou tourné. | Clic sur **"Relier une page"**. |
| `sfx_buy_upgrade.mp3` | Son satisfaisant (caisse enregistreuse ancienne, cliquetis de bois). | Achat d'une **Amélioration**. |
| `sfx_research_complete.mp3` | Son magique/mystique (chime, cloche tibétaine). | Achat d'une **Recherche**. |
| `sfx_error.mp3` | Bruit sourd ou "buzzer" doux. | Clic impossible (pas assez de ressources). |

### Événements
| Nom Fichier | Description | Utilisation |
| :--- | :--- | :--- |
| `sfx_event_pop.mp3` | Son de notification discret (petite cloche ou craquement). | Apparition d'un **Popup**. |
| `sfx_rat_squeak.mp3` | Couinement de rat. | Événement **"Rat de Bibliothèque"**. |
| `sfx_fire_start.mp3` | Crépitement de feu soudain. | Événement **"Début d'Incendie"**. |
| `sfx_void_whisper.mp3` | Murmure "Shhh..." ou voix fantomatique. | Événement **"Murmure du Vide"** / Gain de Savoir. |
| `sfx_achievement.mp3` | Fanfare courte et solennelle (trompette étouffée ?). | Déblocage d'un **Succès**. |

### Fin du Jeu
| Nom Fichier | Description | Utilisation |
| :--- | :--- | :--- |
| `sfx_prestige_burn.mp3`| Son de feu violent, grondement, explosion sourde. | **"Grand Incendie"** (Prestige). |
| `sfx_ending.mp3` | Son de "coupure" de courant ou de fin de disque. | **"Déchirer le Voile"** (Fin du jeu). |
